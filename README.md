# 🚀 EV Charging Reservation Application

An application designed to help users **reserve electric vehicle (EV) charging stations** conveniently.  
The system allows users to register, search for charging stations, and manage their charging reservations efficiently.

## ✨ Key Features

- 🔐 **User Authentication**  
  Users can **register and log in** to access the application.

- ⚡ **Charging Station Reservation**  
  Reserve available EV charging stations easily.

- 🔍 **Search Charging Stations**  
  Find charging stations quickly through the search feature.

- 📜 **Reservation History**  
  View previously booked charging sessions.

- 👤 **Edit Profile**  
  Update user profile information.

- ✅ **Reservation Confirmation**  
  Confirm and manage charging reservations.

### 📌 File Description

| File | Description |
|-----|-------------|
| `MainApp.java` | Main entry point of the application |
| `Login.java` | Handles user login functionality |
| `Register.java` | User registration system |
| `MenuUser.java` | Main menu for regular users |
| `MenuAdmin.java` | Admin menu interface |
| `Reservation.java` | Handles reservation data |
| `ReservationPage.java` | UI page for booking reservations |
| `ReservationManager.java` | Manages reservation logic |
| `ReserveHistory.java` | Displays reservation history |
| `SearchFromName.java` | Search charging stations by name |

| `StationDatabase.java` | Stores station data |
| `PaymentPage.java` | Handles reservation payment |
| `NotificationManager.java` | Sends notifications to users |
| `UserInfo.java` | Stores user profile data |
| `ModernTheme.java` | UI theme styling |
| `AppConstants.java` | Global constants used in the application |
| `Info.java` | Additional application information |
